# Arc Raiders Assets

## Using Fmodel to Extract Assets
### Download fmodel 
- https://fmodel.app/
- Or update your version to latest, as of July 24 2026 Arc Raiders is supported
### Select game engine GAME_ArcRaiders
### Add AES key
- 0x047A8AC14396604CE1BAB46366C0A7FDBE40F66264D4625E2E6D11FF17272D7F
  - "0x" is required for it to work, common error is to omit this and it will fail to decrypt
Add usmap into settings 
- https://github.com/ARC-Data-Raiders/DataRaiders/tree/main/Unpacking
